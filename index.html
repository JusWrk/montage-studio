How to put a carousel on GitHub Pages

Export carousel downloads one HTML file containing the photos, styling and controls. Rename it index.html and upload it into a folder such as project-carousel in your GitHub Pages repository. It will appear at your-site.github.io/project-carousel/ after GitHub publishes the update. It can also be embedded in another page with an iframe. Only the photos included in that exported file become public when you publish it.

To host this editor, upload this file as montage/index.html. The editor works on GitHub Pages or directly from a local file, without a server or access to your GitHub account.
